


# 🚀 API Tester — Lightweight Postman Alternative
<img width="1587" height="842" alt="image" src="https://github.com/user-attachments/assets/0aed3a6e-a6aa-4651-a370-7044b2bfffdd" />

A simple, elegant, and secure **API testing tool** built entirely using **HTML, CSS, and Vanilla JavaScript** — no frameworks, no dependencies.

---

## ✨ Features

- 🔹 **Lightweight & Fast** — Pure front-end app with zero dependencies.
- 🔹 **Supports GET & POST** methods.
- 🔹 **Dynamic Parameter & Header management**.
- 🔹 **Response viewer** with syntax highlighting for JSON, XML, and plain text.
- 🔹 **Error handling** with descriptive messages for CORS/network issues.
- 🔹 **Request history** (session-based, auto-clears on reload).
- 🔹 **Quick Examples** — Test popular public APIs instantly.
- 🔹 **Keyboard Shortcuts**
  - `Ctrl + Enter` → Send request  
  - `Ctrl + K` → Clear all  
  - `Esc` → Close response panel  

---

## 🧠 How It Works

1. Enter your **API URL**.  
2. Choose **HTTP Method** (GET or POST).  
3. Add optional **parameters** and **headers**.  
4. Click **Send Request** or press `Ctrl + Enter`.  
5. Instantly view the **status, headers, and formatted response**.

---

## 🖼️ UI Overview

| Section | Description |
|----------|--------------|
| **Request Configuration** | Configure your API endpoint, method, and params. |
| **Custom Headers** | Add or remove headers dynamically. |
| **Response Viewer** | View formatted response body and headers. |
| **Quick Examples** | Preloaded sample APIs to test instantly. |
| **Error Handling** | Beautiful inline error messages for invalid URLs, CORS, or server failures. |
